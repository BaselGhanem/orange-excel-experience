3-Day Journey

من البيانات اليومية… إلى قرار أوضح.

مش قائمة Functions طويلة. كل يوم له هدف عملي واضح، وكل يوم يبني على اللي قبله.

DAY 01

Think with Excel

حوّل قواعد العمل والبيانات الخام إلى منطق واضح وقابل لإعادة الاستخدام.

  • IF / IFS / AND / OR / IFERROR
  • SUMIFS / COUNTIFS / AVERAGEIFS
  • XLOOKUP + Advanced Search Patterns
  • Dynamic Arrays: FILTER / UNIQUE / SORT
  • Advanced Text & Date Functions
DAY 02

Turn Data into Information

اختصر آلاف الصفوف، جهّز البيانات للشهر القادم، وخلي الاستثناءات تظهر لحالها.

  • PivotTable — your 20-second report
  • Sorting / Filtering / Grouping / Show Values As
  • Slicers / Timeline / Report Connections
  • Power Query — Combine / Clean / Merge / Refresh
  • Conditional Formatting + Data Validation
DAY 03

Turn Information into Decisions

ابنِ تجربة Management واضحة، حرّكها بالفلاتر، وبعدها أتمت الخطوات المتكررة واحمِ الملف.

  • Interactive Dashboard
  • KPI Cards + PivotCharts
  • Slicers + Timeline
  • Record Macro + One-Click Button
  • Protection + Final Executive Challenge
